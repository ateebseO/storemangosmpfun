Frequently asked questions

Quick answers about joining, ranks and support.

How do I join the server?
Open Minecraft, go to Multiplayer, choose Add Server and enter mangosmp.falix.gg.
Which Minecraft version do I need?
Use the latest Java Edition release for the best experience. Check the Discord announcements for the exact supported versions.
Can Bedrock players join?
Yes, if cross-play is enabled on the server. Use the same IP. If it does not connect, ask staff on Discord.
Is the server pay-to-win?
No. Ranks add cosmetics and convenience only.
How do I get a rank after buying?
Open a ticket on Discord with your username. Staff will apply it as soon as possible.
How do I report a player or bug?
Open a ticket on Discord or message an online staff member in game.
The server shows offline. What now?
Check the status on the home page, then ask in Discord. We will post updates if there is maintenance.
